Firewall IPv6. Proteger o próprio roteador. Muito semelhante à configuração IPv4, exceto que temos que lidar com mais protocolos necessários para o funcionamento correto do IPv6. Primeiro, criamos uma ADDRESS-LIST a partir da qual você permite o acesso ao dispositivo: /IPV6 FIREWALL ADDRESS-LIST ADD ADDRESS=fd12:672e:6f65:8899::/64 LIST=ALLOWED. Breve explicação das regras de filtro IPv6: Trabalhar com novos pacotes, aceitar pacotes ESTABLISHED/RELATED; Descartar endereços link-local vindos da interface/lista de interfaces da Internet (pública); Aceitar acesso ao roteador a partir de endereços link-local, aceitar endereços multicast para fins de gerenciamento, aceitar sua lista de endereços de origem para acesso ao roteador; Descartar qualquer outra coisa; /IPV6 FIREWALL FILTER ADD ACTION=ACCEPT CHAIN=INPUT COMMENT="allow established and related" CONNECTION-STATE=ESTABLISHED,RELATED ADD CHAIN=INPUT ACTION=ACCEPT PROTOCOL=ICMPV6 COMMENT="accept ICMPv6" ADD CHAIN=INPUT ACTION=ACCEPT PROTOCOL=UDP PORT=33434-33534 COMMENT="defconf: accept UDP traceroute" ADD CHAIN=INPUT ACTION=ACCEPT PROTOCOL=UDP DST-PORT=546 SRC-ADDRESS=fe80::/10 COMMENT="accept DHCPv6-Client prefix delegation." ADD ACTION=DROP CHAIN=INPUT IN-INTERFACE=in_interface_name LOG=YES LOG-PREFIX=dropLL_from_public SRC-ADDRESS=fe80::/10 ADD ACTION=ACCEPT CHAIN=INPUT COMMENT="allow allowed addresses" SRC-ADDRESS-LIST=ALLOWED ADD ACTION=DROP CHAIN=INPUT. /IPV6 FIREWALL ADDRESS-LIST ADD ADDRESS=fe80::/16 LIST=ALLOWED ADD ADDRESS=xxxx::/48 LIST=ALLOWED ADD ADDRESS=ff02::/16 COMMENT=multicast LIST=ALLOWED. Em certas configurações onde o relay DHCPv6 é usado, o endereço de origem dos pacotes pode não ser da faixa link-local. Nesse caso, o parâmetro SRC-ADDRESS da regra #4 deve ser removido ou ajustado para aceitar o endereço do relay.
