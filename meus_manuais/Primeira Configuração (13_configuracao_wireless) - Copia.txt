Configurando o Wireless
Primeiro, crie um perfil de segurança:
Bash

/interface wireless security-profiles
  add name=myProfile authentication-types=wpa2-psk mode=dynamic-keys \
    wpa2-pre-shared-key=1234567890
Habilite a interface e defina os parâmetros:
Bash

/interface wireless
  enable wlan1;
  set wlan1 band=2ghz-b/g/n channel-width=20/40mhz-Ce distance=indoors \
    mode=ap-bridge ssid=MikroTik-Nome wireless-protocol=802.11 \
    security-profile=myProfile frequency-mode=regulatory-domain \
    set country=brazil antenna-gain=3
Adicione o wireless à bridge local:
/interface bridge port add interface=wlan1 bridge=bridge1
