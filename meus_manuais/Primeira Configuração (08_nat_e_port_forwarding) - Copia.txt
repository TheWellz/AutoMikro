Configuração NAT
A solução para que os computadores locais acessem a internet é alterar o endereço de origem dos pacotes de saída para o IP público do roteador através de uma regra NAT:
Bash

/ip firewall nat
  add chain=srcnat out-interface=ether1 action=masquerade
Se a interface pública for PPPoE, LTE ou outro tipo, o 'out-interface' deve ser definido para essa interface. Clientes atrás do NAT não estão diretamente conectados à Internet, oferecendo proteção adicional.
Port Forwarding
Para tornar um dispositivo local (ex: 192.168.88.254) acessível via RDP (porta TCP 3389):
Bash

/ip firewall nat
  add chain=dstnat protocol=tcp port=3389 in-interface=ether1 \
    action=dst-nat to-address=192.168.88.254
